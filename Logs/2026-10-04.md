## Métiers possibles en informatique / IA
### 1. Construire des logiciels
- **Dev backend**
    - Description : APIs, bases de données, logique métier.
    - **+** : tu aimes structurer et fiabiliser.
    - **−** : tu veux du visuel immédiat.
- ~~**Dev frontend / mobile**~~
    - Description : interfaces utilisateur.
    - **+** : tu aimes le rendu visible et l'ergonomie.
    - **−** : tu préfères les problèmes algorithmiques.
- **Fullstack**
    - Description : backend et frontend, souvent en startup.
    - **+** : tu aimes la polyvalence.
    - **−** : tu veux creuser un seul sujet.
- **Dev embarqué / systèmes / temps réel**
    - Description : proche du matériel (auto, aéro, IoT).
    - **+** : tu aimes le bas niveau et la rigueur.
    - **−** : tu veux itérer vite.
~~- **Dev jeu vidéo / 3D / graphisme**~~
    - Description : moteurs, rendu, gameplay.
    - **+** : tu as une passion pour le domaine.
    - **−** : tu tiens à un bon salaire et à un rythme raisonnable (secteur exigeant).
~~- **Architecte logiciel**~~ (trop tôt, poste de senior)
    - Description : conçoit les grandes lignes des systèmes (poste de senior).
    - **+** : tu aimes la vision d'ensemble.
    - **−** : tu veux coder tout le temps.
~~- **Ingénieur qualité / test / QA automation**~~
    - Description : garantit la fiabilité des logiciels.
    - **+** : tu es méthodique.
    - **−** : tu veux créer plutôt que vérifier.
### ~~2. Infrastructure, fiabilité, sécurité~~
~~- **DevOps / Cloud / SRE**~~
    - Description : déploiement, automatisation, disponibilité.
    - **+** : tu aimes que « ça tourne » et résoudre des incidents.
    - **−** : tu supportes mal les astreintes et le stress de production.
~~- **Platform engineer**~~
    - Description : construit les outils internes pour les autres développeurs.
    - **+** : tu aimes aider tes collègues.
    - **−** : tu veux être proche de l'utilisateur final.
~~- **Cybersécurité (pentest, SOC, GRC, sécurité applicative)**~~
    - Description : attaquer ou défendre des systèmes.
    - **+** : tu as la curiosité du « comment ça casse ».
    - **−** : tu n'aimes pas la veille constante ni la pression d'incident.
~~- **Administrateur systèmes / réseaux**~~
    - Description : exploitation d'infrastructures.
    - **+** : tu aimes le concret et le technique.
    - **−** : tu veux plus de création.
### 3. Données et IA (ton bonus)
~~- **Data engineer**~~
    - Description : pipelines, entrepôts de données.
    - **+** : tu aimes construire des tuyaux solides.
    - **−** : tu veux faire des modèles.
~~- **Data analyst / BI**~~
    - Description : analyses et tableaux de bord pour aider à décider.
    - **+** : tu aimes communiquer des résultats aux métiers.
    - **−** : tu veux du code lourd.
- **Data scientist**
    - Description : analyses et modèles prédictifs sur des problèmes métier.
    - **+** : tu as de la curiosité, tu aimes les statistiques et raconter ce que disent les données.
    - **−** : tu détestes l'ambiguïté (données sales, questions floues).
- **ML engineer**
    - Description : entraîne et intègre des modèles dans des produits.
    - **+** : tu aimes mélanger dev et IA.
    - **−** : tu veux faire de la recherche pure.
- **MLOps**
    - Description : industrialise, déploie et surveille les modèles.
    - **+** : tu aimes DevOps et IA.
    - **−** : tu veux concevoir les modèles toi-même.
- **AI / LLM engineer**
    - Description : construit des applis avec des LLM (RAG, agents, évaluation).
    - **+** : tu veux du concret sur ce qui est actuel.
    - **−** : le domaine bouge très vite, avec beaucoup d'incertitude.
- **AI safety / évaluation / gouvernance IA**
    - Description : robustesse, biais, conformité (AI Act).
    - **+** : tu t'intéresses à l'éthique et à la réglementation.
    - **−** : tu veux uniquement de la technique pure.
- **Prompt / AI product engineer, solutions IA** (why not mais pas sûr)
    - Description : intègre l'IA aux processus métiers.
    - **+** : tu aimes le concret rapide.
    - **−** : tu veux une expertise théorique profonde.
### 4. Chercher et innover
- **Chercheur en labo (public ou privé)** (hyper intéressant mais jsp si j'ai l'énergie)
    - Description : publie et invente de nouvelles méthodes ; thèse quasi obligatoire.
    - **+** : tu adores lire des papiers et creuser longtemps.
    - **−** : tu veux des résultats rapides.
- **Research engineer**
    - Description : implémente et passe à l'échelle le travail des chercheurs, sans thèse obligatoire.
    - **+** : tu veux un compromis entre recherche et ingénierie.
    - **−** : tu veux définir toi-même les axes de recherche.
- **R&D industrielle / innovation**
    - Description : prototypes et veille dans une entreprise.
    - **+** : tu as une curiosité large.
    - **−** : tu supportes mal que les prototypes n'aboutissent pas toujours en produit.
- **Doctorant CIFRE**
    - Description : thèse réalisée en entreprise.
    - **+** : tu hésites entre recherche et industrie.
    - **−** : tu ne veux pas t'engager 3 ans sur un seul sujet.
### 5. Travailler avec des clients et des métiers
- **Consultant IT / Data / IA (ESN, cabinet)**
    - Description : missions variées chez des clients.
    - **+** : tu aimes la variété, apprendre vite et le contact.
    - **−** : tu veux de la stabilité et un seul produit.
- ~~**Consultant en stratégie / transformation digitale**~~
    - Description : conseil de haut niveau, moins technique.
    - **+** : tu es à l'aise à l'oral et en synthèse.
    - **−** : tu veux garder les mains dans la technique.
- ~~**Solutions / sales engineer (avant-vente)**~~
    - Description : démontre et adapte un produit technique aux clients.
    - **+** : tu aimes mêler technique et relationnel.
    - **−** : tu détestes la dimension commerciale.
- **Customer success / support technique avancé**
    - Description : accompagne les clients sur un produit.
    - **+** : tu aimes la pédagogie.
    - **−** : tu veux construire plutôt qu'accompagner.
- **Forward deployed engineer**
    - Description : ingénieur envoyé chez le client pour déployer une solution.
    - **+** : tu aimes le terrain et le code.
    - **−** : tu veux rester dans une équipe produit stable.
- ~~**Technical writer / developer advocate**~~
    - Description : documentation, conférences, communauté.
    - **+** : tu aimes expliquer et écrire.
    - **−** : tu veux coder à temps plein.
### ~~6. Orienter, décider, coordonner~~
~~- **Product manager**~~
    - Description : décide quoi construire et pourquoi.
    - **+** : tu t'intéresses aux utilisateurs et au business.
    - **−** : tu veux rester dans le code.
~~- **Chef de projet / delivery manager**~~
    - Description : planning, budget, gestion d'équipe.
    - **+** : tu aimes l'organisation et la communication.
    - **−** : tu veux rester technique.
~~- **Tech lead / engineering manager**~~
    - Description : encadre une équipe technique (après quelques années).
    - **+** : tu aimes faire grandir les autres.
    - **−** : tu veux garder ton temps de code.
~~- **Business analyst / AMOA**~~
    - Description : traduit les besoins métier en spécifications.
    - **+** : tu aimes faire l'interface entre technique et métier.
    - **−** : tu veux construire toi-même.
~~- **Data / AI product owner**~~
    - Description : pilote un produit basé sur les données.
    - **+** : tu aimes la vision produit appliquée à la donnée.
    - **−** : tu veux entraîner les modèles toi-même.

### ~~7. Autres~~
~~- **Quant / fintech / finance de marché**~~
    - Description : modèles, trading, gestion du risque.
    - **+** : tu aimes les maths et la finance, et tu vises un salaire élevé.
    - **−** : tu supportes mal la pression forte.
~~- **Entrepreneuriat / fondateur de startup**~~ (trop tôt, ou alors à côté pour un petit projet)
	- Description : créer son propre produit.
	- **+** : tu tolères le risque et veux de l'autonomie.
	- **−** : tu as besoin d'un revenu stable.
~~- **Freelance**~~ (trop tôt)
    - Description : missions indépendantes (souvent après quelques années).
    - **+** : tu veux de la liberté et acceptes des revenus variables.
    - **−** : tu veux de la sécurité et un collectif d'équipe.
~~- **Enseignement / formation**~~ (trop tôt)
    - Description : enseignant-chercheur ou formateur.
    - **+** : tu aimes transmettre.
    - **−** : tu supportes mal la répétition ou les contraintes académiques.
~~- **Journalisme tech, investissement (VC), politique publique du numérique**~~ (trop tôt)
    - Description : profils techniques recherchés pour analyser un écosystème.
    - **+** : tu aimes l'analyse d'écosystème plus que la production.
    - **−** : tu veux produire du code ou des systèmes concrets.
