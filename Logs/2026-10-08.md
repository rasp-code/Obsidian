- #### To remember
	- PAY ATTENTION WITH LISTS (and equivalent object), `list2 = list1` is usually a bad idea ! Prefer `list2 = list(list1)` or `list2 = list1.copy()`
	- get used to "shortcuts", like `list(range(5))` etc.
	- `collections.defaultdict`, types not hashable, hashable = immutable
	- `sorted`, lambda functions
	- unpack operator `*` (e.g. `a, *b, c = range(n) and f(*list)`) and `**` (e.g. `dict3 = {**dict1, **dict2}`)
	- `zip`, `enumerate`
	- `print` evaluates all the parameters *then* displays, whereas an f-string is sequential
	- the default value of a parameter is only created once, so if it's a list it's shared across all function calls (useful for accumulators)
	- `[e] * n` gives `[e, ..., e]` and not `[[e], ..., [e]]`, `[[e]] * n` copies the list reference, so every element links to the same list, to avoid that use comprehension instead of `*`
	- `copy` is shallow and works for only one depth, `copy.deepcopy` works for nested list
	- `[y for x in M for y in x]` and not ~~`[y for y in x for x in M]`~~ (same order as regular nested fors)
	- slice a list with `[start:stop:step]`, hence `::-1` reverses the list
	- iterable vs iterator, generator (`yield`), lazy generator (`(foo for bar in baz)`)
	- prefer `random.Random.method()` (local instance) over `random.method()` (global)
	- `__init__(self, *params)` and `super().__init__(*params)`
	- `@decorator` takes a function and returns a function (`return wrapper`), `@wraps(function)` copies `__name__`,`__doc__` and other meta data, always use it when defining your annotation.
	- `finally` use with `try` nor `catch` for code to be executed in all cases
	- use `time.perf_counter()` over `time.time()` (more precision)
	- Context Manager: use either a class with `__enter__` and `__exit__` or a function with `@contextmanager`
	- what is a closure ?
	- type annotation (`a: list[float | int]`, `Callable[[int, float], int]`, `-> None`, etc.), `mypy` and `pyright`
	- what is a dataclass, and the class decorator `@dataclass`, annotation makes the attribute instance-owned, without annotation it is class-owned !
	- `except OriginalException: raise MyException from e` permet de conserver également le message de `OriginalException` en plus de celui de `MyException`
