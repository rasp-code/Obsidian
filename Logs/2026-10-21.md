# Remise à niveau
## Carte de l'IA : du fondamental au pratique (générée par Claude)
### Mon objectif
- **0. Fondations**
  -  Mathématiques
    -  Algèbre linéaire (matrices, SVD)
    -  Probabilités et statistiques (Bayes, MLE)
    -  Calcul et optimisation (gradient, descente de gradient)
  -  Outils : Python, NumPy, pandas, matplotlib

- **1. Machine learning classique**
  - Apprentissage supervisé
    -  Régression : linéaire, régularisation (L1/L2)
    -  Classification : logistique, k-NN
    -  Méthodes à base d'arbres : random forest, gradient boosting
  - Apprentissage non supervisé
    -  Clustering : k-means
    -  Réduction de dimension : PCA
  - Méthodologie
    -  Biais-variance, sur/sous-apprentissage
    -  Validation croisée, métriques (F1, AUC, MSE…)
    -  Preprocessing, feature engineering, fuite de données

- **2. Deep learning**
  -  Bases : perceptron multicouche, rétropropagation
  -  Entraînement : fonctions de perte, SGD/Adam, normalisation, dropout
  -  Framework : PyTorch
  - Architectures
    -  CNN (images)
    -  RNN/LSTM (séquences, historique)
### Bonus
- **3. Transformers et modèles génératifs** `[M4]`
  -  Embeddings et tokenisation
  -  Attention, self-attention, architecture Transformer
  -  Familles de modèles : encodeur (BERT), décodeur (GPT)
  -  Pré-entraînement vs fine-tuning
  -  Génération d'images : diffusion (aperçu), GAN/VAE (culture)
- **4. LLM appliqués** `[M5]`
  -  Prompt engineering, sorties structurées, function calling
  -  RAG : chunking, embeddings, base vectorielle, reranking
  -  Fine-tuning : full, LoRA/QLoRA
  -  Alignement (culture) : RLHF, DPO
  -  Agents : boucle outil/raisonnement
  -  Évaluation : jeux de test, LLM-as-judge, hallucinations
- **5. Domaines d'application** *(selon le stage visé)*
  -  Vision par ordinateur : classification, détection, segmentation
  -  NLP : classification de texte, NER, résumé, QA
  -  Données tabulaires et séries temporelles : prévision, détection d'anomalies
  -  Systèmes de recommandation
  -  Audio/parole (culture)
  -  Apprentissage par renforcement (culture)
- **6. Ingénierie et production** `[M6]`
  -  Qualité de code : Git, tests, environnements
  -  Déploiement : FastAPI, Docker, bases cloud
  -  Suivi d'expériences : MLflow / W&B, reproductibilité
  -  Monitoring : dérive des données, coût, latence
- **7. Transversal**
  -  IA responsable : biais, vie privée/RGPD, sécurité des LLM
  -  Explicabilité : SHAP, importance des features
- **8. Employabilité** `[M7]`
  -  Projets portfolio (tabulaire, deep learning, LLM/RAG)
  -  ML system design
  -  Questions d'entretien
  -  Papiers fondateurs (Attention Is All You Need, ResNet…)
