- #### To remember
	- collections.defaultdict, types not hashable, hashable = immutable
	- sorted, lambda functions
	- unpack operator * (a, \*b, c = range(n) and f(\*list))
	- zip, enumerate
	- print evaluates all the parameters *then* displays, whereas an f-string is sequential
	- the default value of a parameter is only created once, so if it's a list it's shared across all function calls (useful for accumulators)
	- \[e] \* n gives \[e, ..., e] and not \[\[e], ..., \[e]], \[\[e]] \* n copies the list reference, so every element links to the same list, to avoid that use comprehension instead of \*
	- copy is shallow and works for only one depth, copy.deepcopy works for nested list
	- \[y for x in M for y in x] and not ~~\[y for y in x for x in M]~~ (same order as regular nested fors)
