**Feature engineering** is the manual creation, transformation and selection of [[Feature|features]], using domain knowledge, to improve model performance.

**Operations**
- Creation: new features combining or aggregating existing ones.
- Transformation: see [[Data Transformation]].
- Selection: keeping only the relevant features.

**Comparison**
- [[Representation Learning]] learns features automatically.
