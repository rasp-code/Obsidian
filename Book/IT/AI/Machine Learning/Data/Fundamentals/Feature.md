A **feature** is an individual measurable property of an example, used as an input variable of a model.

**Feature vector**
- The $d$ features of an example form a [[Vector]] $\mathbf{x} \in \mathbb{R}^d$: the [[Input]] of the model.
- The set of all possible feature vectors is the **feature space**.
- In a [[Dataset]], each feature is a column of the data matrix.

**Condition**
- A feature must be numerical to be used by most models: categorical features are encoded (see [[Data Transformation]]).
