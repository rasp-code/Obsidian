A **label** is the target value associated with an example of a [[Dataset]]: the [[Output]] a model is expected to produce for it. It is denoted $y$.

**Properties**
- It is the reference (ground truth) against which the model output is compared.
- It comes from annotation, from measurement, or is derived automatically from the data.
- It may be wrong (label noise).
- An example without label is **unlabeled**.
