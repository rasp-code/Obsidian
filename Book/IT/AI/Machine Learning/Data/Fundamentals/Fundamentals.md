The **fundamentals of data** are the basic objects describing the data used and produced in [[Machine Learning]].

**Notions**
- [[Dataset]]: a collection of examples.
- [[Feature]]: a measurable property of an example.
- [[Input]]: what the model receives, $x$.
- [[Label]]: the target value of an example, $y$.
- [[Output]]: what the model produces, $\hat{y}$.
