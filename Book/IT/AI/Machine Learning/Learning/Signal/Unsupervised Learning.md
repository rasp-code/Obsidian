**Unsupervised learning** is a learning setting where the data has no [[Label]]: the model learns structure from the [[Input|inputs]] of a [[Dataset]] $\{x_i\}_{i=1}^{N}$ alone.

**Principle**
- The [[Signal]] is an objective on the structure of the data: similarity, density, compression.

**Comparison**
- [[Supervised Learning]] uses labels as the signal.
