The **learning algorithm** is the procedure that iteratively updates the [[Parameters]] of a model to minimize the [[Objective]].

**Notions**
- [[Update Rule]]: computation of each parameter update.
- [[Learning Rate]]: size of each step.
- [[Batch]], [[Mini-Batch]]: examples used for one update.
- [[Epoch]]: one pass over the dataset.
- [[Gradient-Based]]: algorithms using the gradient of the loss.
