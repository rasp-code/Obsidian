Uncovering patterns, groups or representations in data.

## Types

- [[Clustering]]: group similar items
- [[Anomalie Detection]]: spot items that deviate
- [[Association Rule Learning]]: find items that occur together
- [[Density Estimation]]: model how likely data is
- [[Dimensionality Reduction]]: compress data into fewer variables
- [[Representation Learning]]: learn useful features of the data
