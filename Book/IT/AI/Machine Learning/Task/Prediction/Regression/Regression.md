**Regression** is the [[Prediction]] task of estimating a continuous numerical value from an [[Input]].

**Formulation**
- A function $f : \mathcal{X} \to \mathbb{R}^k$, usually with $k = 1$, learned from examples with numerical [[Label|labels]].

**Properties**
- The [[Output]] is continuous and ordered: errors have a magnitude, measured by the [[Loss Function]].

**Models**
- [[Linear Regression]]: output linear in the features.

**Comparison**
- [[Classification]] predicts a discrete class.
