The **fundamentals of neural networks** are the building blocks and basic structures common to all architectures.

**Notions**
- [[Activation Function]]: nonlinearity applied by each neuron.
- [[Perceptron]]: a single neuron with a step activation.
- [[MLP]]: fully connected feedforward network.
- [[Deep Neural Network]]: network with several hidden layers.
