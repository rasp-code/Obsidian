**Neural network architectures** are the ways layers are organized and connected, each suited to a structure of data or to a task.

**Architectures**
- [[CNN]]: grids such as images, by convolution.
- [[RNN]]: sequences, by recurrence.
- [[Transformer]]: sequences, by attention.
- [[GNN]]: graphs, by message passing.
- [[Autoencoder]]: compression by reconstruction.
- [[VAE]]: probabilistic, generative autoencoder.
- [[GAN]]: generator trained against a discriminator.
- [[Diffusion Model]]: generation by iterative denoising.
