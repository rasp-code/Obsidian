A **vector** is an element of a [[Vector Space]]: an object that can be added to other vectors and multiplied by scalars.

In $\mathbb{R}^n$, a vector is an ordered list of $n$ real numbers:

$$\mathbf{x} = (x_1, \dots, x_n)^\top$$

Geometrically, it represents a point, or a magnitude and a direction, in $n$-dimensional space.

**Operations**
- Addition: $(\mathbf{x} + \mathbf{y})_i = x_i + y_i$.
- Scalar multiplication: $(a\mathbf{x})_i = a\,x_i$.
- Euclidean norm (length): $\|\mathbf{x}\|_2 = \sqrt{\sum_i x_i^2}$.
