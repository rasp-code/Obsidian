The **transpose** of a [[Matrix]] $A \in \mathbb{R}^{m \times n}$ is the matrix $A^\top \in \mathbb{R}^{n \times m}$ obtained by exchanging rows and columns:

$$(A^\top)_{ij} = a_{ji}$$

**Properties**
- $(A^\top)^\top = A$.
- $(A + B)^\top = A^\top + B^\top$.
- $(cA)^\top = c\,A^\top$.
- $(AB)^\top = B^\top A^\top$ (the order is reversed).

**Symmetric matrix**
- A square matrix is symmetric if and only if $A = A^\top$.
