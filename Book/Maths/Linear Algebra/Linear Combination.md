A **linear combination** of [[Vector|vectors]] $v_1, \dots, v_k$ of a [[Vector Space]] is a vector of the form

$$a_1 v_1 + a_2 v_2 + \dots + a_k v_k = \sum_{i=1}^{k} a_i v_i$$

where $a_1, \dots, a_k$ are [[Scalar|scalars]] called the **coefficients**.

**Characteristics**
- The result is always a vector of the same vector space.
- A combination with all coefficients equal to $0$ is the **trivial combination** and gives the zero vector.
- A linear combination uses only vector addition and scalar multiplication.
