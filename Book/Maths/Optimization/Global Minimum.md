A point $x^*$ is a **global minimum** of a function $f$ over a domain $D$ if no point of $D$ has a lower value:

$$\forall x \in D : \quad f(x^*) \leq f(x)$$

- Every global minimum is also a [[Local Minimum]]; the converse is false.
- The minimal value $f(x^*)$ is unique, but it can be attained at several points.
- A function may have no global minimum (e.g. $f(x) = x$ on $\mathbb{R}$, or $f(x) = e^x$).
