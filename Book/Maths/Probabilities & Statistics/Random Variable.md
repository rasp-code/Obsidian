A **random variable** is a [[Function|function]] $X : \Omega \to E$ from a [[Sample Space]] $\Omega$ to a set $E$ (most often $\mathbb{R}$), that maps each [[Outcome]] $\omega$ to a value $X(\omega)$.

**Types**
- Discrete: takes a finite or countable number of values.
- Continuous: takes values in an interval or in $\mathbb{R}$, with a density (see [[Probability Distribution]]).

**Notation**
- $X$ is the variable, $x$ a value it can take.
- $P(X = x)$ is the probability that $X$ takes the value $x$.
